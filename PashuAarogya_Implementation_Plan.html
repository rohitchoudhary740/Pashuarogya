1Approach — one chain, from the shed to the State

Today a sick animal is spotted by a farmer who has no channel, while the State that needs the signal hears it weeks later on paper. We close that loop inside one platform: a symptom spoken in Marathi becomes a triaged case, a lab-confirmed outbreak, a detected cluster, an auto-issued task and a paid compensation claim — with no re-entry at any step. Reporting is made to pay, which is what actually fixes under-reporting.

2Phased rollout — each phase gated on a number, not a date

PHASE 0 · DONE
Working Prototype
  • All six innovations built and demoable end-to-end
  • 7 role dashboards, 53 REST endpoints
  • 24 months of seeded epidemiology
  • Deployed on Render + Postgres, public HTTPS
GATE ✓ full loop runs live in under 2 min
PHASE 1 · MONTH 1–3
Block Pilot
  • One block · ~50 villages · ~2 000 animals
  • Read-only sync with Bharat Pashudhan (BPID)
  • Train field workers; 1962 call-centre script
  • Vet sign-off on every triage output
GATE ≥60% of reports filed by farmers, not staff
PHASE 2 · MONTH 4–9
District Rollout
  • One full district, all blocks + DDL laboratory
  • Two-way INAPH / LHDCP integration
  • Movement permits at checkposts and markets
  • Compensation disbursed through DBT
GATE detection lead-time beats paper by ≥7 days
PHASE 3 · MONTH 10–18
State Scale
  • 36 districts on MahaIT / NIC cloud
  • Breed model on a GPU node; more languages
  • NADCP drive planning driven by the forecast
  • Open API for ICAR and One Health / IDSP
GATE State SITREP replaces the manual return

4Risks we designed against

RiskMitigation already in the build
Farmers under-report — no incentiveReport → claim → approved compensation. Reporting pays.
No network in the fieldOffline-first PWA — the report queues locally and syncs on reconnect
No smartphone, low literacyMarathi–Hindi voice, IVR on 1962, SMS, icon-first UI
False alarms erode trustp-value threshold plus a vet-confirmation gate before escalation
Wrong AI diagnosis — liabilityEmits suspected category + severity + route, never a diagnosis
Duplicate entry against BPIDAPI sync with Bharat Pashudhan; the tag ID is the shared key
GPU cost at scale5 of 6 features need no model; vision degrades to manual entry, honestly
Officer adoptionTasks are auto-created from clusters — the queue does the chasing
